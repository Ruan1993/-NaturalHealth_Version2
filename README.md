# Natural Health Virtual Mall V2

An immersive, WebGL-led wellness market created with Vite, Vanilla JavaScript, Three.js, GSAP, and Lenis.

## Run locally

1. Install dependencies with `npm install`.
2. Start the development server with `npm run dev`.
3. Create a production build with `npm run build`.

Phase 1 establishes the world, camera movement, lighting, floor, entry experience, and responsive progress UI.
